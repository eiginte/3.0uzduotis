Detailed Description

Paveldima klasė iš Zmogus, skirta studentų duomenims saugoti ir apdoroti.

Studentas klasė saugo studento namų darbų pažymius, egzamino pažymį, apskaičiuoja vidurkį ir medianą, palaiko Rule of Three (Copy constructor ir assignment) bei įgyvendina abstrakčią Zmogus::isvesti() funkciją.
