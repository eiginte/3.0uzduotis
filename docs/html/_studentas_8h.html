Detailed Description

Studentas klasės deklaracija.

Šiame faile aprašyta Studentas klasė, paveldima iš Zmogus. Studentas saugo namų darbų pažymius, egzamino pažymį, skaičiuoja vidurkį ir medianą, įgyvendina abstrakčią Zmogus::isvesti() funkciją ir palaiko Rule of Three.
